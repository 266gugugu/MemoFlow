## 1. 产品概述

### 1.1 产品愿景  
打造一款专注用户体验的现代化桌面备忘录应用，通过智能悬浮窗与高效交互设计，帮助用户在不中断当前工作流的前提下，快速记录、检索与组织碎片化想法与待办事项。

### 1.2 目标用户  
- 知识工作者（如医学生、程序员、研究人员）  
- 需频繁记录灵感/待办但排斥复杂笔记工具的用户  
- 追求极简操作与高专注度场景下的使用者  

## 2. 核心功能需求（MVP）

| 模块 | 功能点 | 优先级 | 描述 | 验收标准 |
|------|--------|--------|------|----------|
| **悬浮窗管理** | 自动吸附与收起 | P0 | 窗口默认吸附顶部；鼠标移出后自动收起为细线（高度 ≤ 5px），靠近边缘自动展开 | 收起/展开动画流畅；响应延迟 ≤ 300ms；支持主屏/扩展屏边缘识别 |
| | 动态高度自适应 | P0 | 窗口高度随内容动态变化（最小高度 50px，最大 80% 屏高） | Markdown 渲染后内容完整显示，无滚动条溢出 |
| | 多屏防丢失 | P1 | 检测窗口坐标异常（如移出所有屏幕），自动回位至主屏顶部 | 异常位移后 1s 内触发回位动画 |
| **内容管理** | 备忘录列表展示 | P0 | 顶部搜索框支持实时关键词过滤（标题+正文+标签） | 输入即过滤，延迟 ≤ 200ms；高亮匹配项 |
| | 内嵌编辑 | P0 | 双击列表项进入行内编辑；支持 Markdown 语法（`#` `**` `-` `[x]`等） | 编辑状态与展示状态无缝切换；语法实时渲染 |
| | 标签系统 | P1 | 独立标签选择器（非正文输入）；支持 `#标签` 快捷添加；多标签筛选 | 标签不污染正文；同名标签自动合并；筛选逻辑为“或”关系 |
| | 快捷录入 | P1 | 底部固定输入框，Enter 提交，支持 `#耳鼻喉` 快速附加标签 | 提交后自动清空；新条目置顶 |
| **系统集成** | 托盘控制 | P0 | 关闭主窗 → 隐藏至系统托盘；右键托盘菜单：「显示」「退出」 | 托盘图标清晰可辨；退出为彻底进程结束 |
| | 数据持久化 | P0 | 自动保存至同目录 `memos.json`；设置保存至 `settings.json` | 写入频率 ≤ 1s/次；崩溃恢复支持（本地缓存） |
| **个性化设置** | 暗色主题 | P0 | 默认暗色 UI（#1e1e1e / #2d2d2d / #cccccc）；符合 WCAG AA 对比度 | 无闪烁切换（未来扩展） |
| | 行为配置 | P1 | 可配置：<br>• 自动隐藏延迟（200ms–5s）<br>• 是否始终置顶<br>• 开机自启（Windows 注册表写入） | 配置即时生效；自启注册可逆 |

## 3. 非功能性需求

| 类别 | 要求 |
|------|------|
| **性能** | • 首次启动 ≤ 2s（本地）<br>• 列表渲染 100 条 ≤ 500ms<br>• 搜索响应 ≤ 200ms |
| **稳定性** | • 7×24 运行无内存泄漏（≤ 5MB/h）<br>• 写入异常自动回滚，保障数据不损坏 |
| **兼容性** | • Windows 10 21H2+ / Windows 11<br>• Python 3.10–3.12（打包后无需环境） |
| **安全性** | • 本地存储，无网络权限<br>• 敏感操作（如退出）需二次确认（未来扩展） |
| **可维护性** | • 模块化设计（UI / Logic / Storage 分离）<br>• 日志分级（INFO/DEBUG/ERROR） |
